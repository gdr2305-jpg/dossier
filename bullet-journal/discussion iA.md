# discussion iA

## Objet
Résumé de la discussion ayant conduit à la création d'un premier modèle de bullet journal PDF pour usage sur tablette avec stylet, en particulier dans Samsung Notes.

## Point de départ
Le besoin exprimé était de disposer d'un bullet journal réellement adapté à un usage manuscrit sur tablette, avec une priorité donnée à l'esprit « bullet journal » plus qu'à un simple planner décoratif.

## Recherche et cadrage
La réflexion a porté sur les solutions existantes de bullet journal et de prise de notes/planning, puis sur l'idée de construire un modèle PDF personnalisé à importer dans Samsung Notes.

Le premier modèle retenu devait être une page journalière.

## Principes retenus pour la page journalière
La page devait rester sobre, fonctionnelle, orientée écriture au stylet, et utile contre le problème des listes de tâches trop longues.

Les principes structurants retenus ont été les suivants :
- page simple et aérée ;
- vraie logique de bullet journal ;
- espace important pour le journal rapide ;
- limitation volontaire des priorités ;
- compatibilité avec une utilisation sur tablette Samsung.

## Choix de format et de fond
Plusieurs choix ont été arrêtés :
- abandon du format A4 au profit du format A5, jugé plus naturel pour un usage de type carnet ;
- orientation portrait ;
- fond en dot grid 5 mm ;
- dots demandés ensuite un peu plus visibles.

## Structure de la page décidée
La page journalière a été organisée autour des blocs suivants :
- Date ;
- Cap du jour ;
- Temps ;
- État du jour ;
- Les 3 non négociables ;
- Bonus si élan ;
- Journal rapide ;
- À reporter ;
- Clôture du jour.

## Ajustements demandés ensuite
Des modifications précises ont été apportées à la première version :
- remplacement du champ date par la forme `Date : .. / .. / ..` ;
- passage du `Cap du jour` à une seule ligne ;
- simplification de `État du jour` en `NRJ` et `Angoisse` ;
- réduction du bloc `Bonus si élan` à 2 lignes ;
- augmentation légère de la visibilité des dots.

## Fichier produit
Un PDF de page journalière A5 a été généré puis modifié selon les ajustements ci-dessus.

## Besoins identifiés pour produire d'autres modèles
La discussion a aussi permis de clarifier les informations nécessaires pour produire ce type de PDF :
- format de page ;
- liste des blocs ;
- texte exact à imprimer ;
- type de fond (dots, lignes, etc.) ;
- niveau de sobriété graphique ;
- usage réel (tablette, stylet, impression, densité d'écriture).
